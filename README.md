<h2 align="center">✨ Overview ✨</h2>

<p align="center">
  This library helps luthiers, acousticians, and DIY builders calculate the Helmholtz resonance frequency of air cavities based on measurable physical properties. 
  It's cleanly separated into variable formulas and solving formulas to stay modular and easy to expand.
</p>
